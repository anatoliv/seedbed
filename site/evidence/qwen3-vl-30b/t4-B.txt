## Root cause
The `showMenu` function sets the menu on the status item but then immediately sets it to `nil` after calling `performClick`, which causes the menu to disappear before it can be displayed. The issue is on line 10 in the `showMenu` function: `statusItem.menu = nil` is executed right after showing the menu, which cancels the menu display.

## Fix
```swift
private func showMenu() {
    let menu = NSMenu()
    menu.addItem(withTitle: "Open", action: #selector(open), keyEquivalent: "")
    menu.addItem(withTitle: "Quit", action: #selector(NSApplication.terminate(_:)), keyEquivalent: "q")
    statusItem.menu = menu
    statusItem.button?.performClick(nil)
}
```

## Verification
- Input: Right mouse click on status item
- Before fix: Menu appears briefly then disappears because `statusItem.menu = nil` is called immediately after
- After fix: Menu remains visible after click because the menu is not immediately cleared
